# desi-openspace-visualization

This repository contains a two-step data processing pipeline designed to convert Dark Energy Spectroscopic Instrument (DESI) catalogs into 3D Cartesian coordinates and color-indexed datasets optimized for the OpenSpace visualization engine.

## Pipeline Overview

* **`fitstocsv_fullsurvey.ipynb`**: A Jupyter Notebook that ingests raw DESI `.fits` catalogs and applies strict quality assurance filters[cite: 1]. It calculates comoving distances and transforms celestial sky coordinates into flat 3D Cartesian coordinates (x, y, z)[cite: 1]. Additionally, it utilizes the `kcorrect` library to fit Spectral Energy Distributions and computes rest-frame optical colors to assign initial RGB values[cite: 1].
* **`generate.py`**: A Python script that loads the output `.csv` file generated by the notebook[cite: 2]. It quantizes the original galaxy RGB values into exactly 1000 distinct color buckets (IDs 0 through 999) to save computing time[cite: 2]. It then generates a `.cmap` file for OpenSpace and exports a final indexed `.csv` with a `color_id` column[cite: 2].

## Installation & Dependencies

This pipeline requires several scientific and astronomical Python libraries[cite: 1, 2]. You can install the required dependencies using `pip`:

`pip install numpy pandas matplotlib scipy astropy kcorrect`

## Usage Instructions

1. Execute `fitstocsv_fullsurvey.ipynb` to clean the raw `.fits` data and export the initial spatial `.csv`[cite: 1].
2. Open `generate.py` and update the `INPUT_CSV_PATH`, `OUTPUT_CSV_PATH`, and `CMAP_OUTPUT_PATH` variables to match your local file system[cite: 2].
3. Run `generate.py` to produce the `.cmap` and indexed `.csv` files required by OpenSpace[cite: 2].
